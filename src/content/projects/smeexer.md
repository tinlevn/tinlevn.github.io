Smeexer is an e-commerce prototype for mechanical keyboard products, built as a
full-stack application with a shopping cart flow and Stripe payment integration.

## Highlights

- Shopping cart and checkout flow with Stripe payment integration
- REST API backend implemented with ASP.NET 6 Web API
- Angular 13 frontend consuming the API

## Stack

| Layer     | Technology         |
| --------- | ------------------ |
| Frontend  | Angular 13         |
| Backend   | ASP.NET 6 Web API  |
| Payments  | Stripe             |
| Language  | C#                 |
